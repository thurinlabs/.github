## Prove more. Reveal less.

Thurin Labs builds open, decentralized identity infrastructure: PGP keys claimed on Ethereum addresses, checked by anyone, with no backend to trust and no data collected.

### Thurin.id

- **[thurin.id](https://thurin.id)**: look up anyone's PGP key by ENS name, address, or fingerprint, and [claim your own](https://thurin.id/attest) on your Ethereum address
- **[Thurin CLI](https://docs.thurin.id/#/cli)**: the same from a terminal (`npx @thurinlabs/thurin@latest`), plus a keyserver plain gpg can use
- **[identity-kit](https://github.com/thurinlabs/identity-kit)**: the one library that reads and checks claims, behind all of them
- **[PGPRegistry](https://github.com/thurinlabs/pgp-registry)**: the contract. Immutable, no admin, no fees

### Tools

- **[mathom](https://mathom.thurinlabs.id)**: air-gapped PGP key custody and signing, built from an old laptop
- **[noir-audit-skill](https://github.com/thurinlabs/noir-audit-skill)**: a Claude Code skill for auditing Noir zero-knowledge circuits
